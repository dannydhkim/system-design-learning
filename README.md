# System Design Learning

Interactive system design study using [Breakscale](../breakscale/) as a simulator.
Focus: **ML system design** with general distributed systems foundations.

## How to study

1. Run breakscale: `cd ../breakscale && bun dev` → http://localhost:5173
2. Review questions in `questions/` — each has a spaced repetition schedule
3. Work through `curriculum.md` for the learning path
4. Build systems in breakscale to test understanding

## Structure

- `curriculum.md` — Full learning path with topics and progress
- `questions/` — ANKI-style flashcards with spaced repetition tracking
- `breakscale-reference.md` — Component reference so we don't re-read source
- `ml-system-design.md` — ML-specific system design patterns and mappings
